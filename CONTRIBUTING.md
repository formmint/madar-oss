# Contributing to MADAR OSS | المساهمة في مَدار

[العربية](#العربية) · [English](#english)

## العربية

1. تصفّح [المهام المفتوحة](https://github.com/formmint/madar-oss/issues). إذا اخترت مهمة، علّق عليها بخطتك المختصرة لتنسيق العمل. للتبليغ عن خلل، اذكر خطوات التكرار والنتيجة المتوقعة والفعلية والمتصفح ولغة الواجهة.
2. اعمل Fork للمستودع وأنشئ فرعًا من `main` لكل تعديل. الكود الحالي في `index.html`. اتبع [تعليمات التشغيل](README.md#جرّب-النسخة-الحالية).
3. إذا غيّرت نصًا في الواجهة، حدّث العربية والإنجليزية. جرّب الاتجاهين وعرضًا ضيقًا، واستخدم بيانات وهمية في الاختبارات ولقطات الشاشة.
4. افتح Pull Request إلى `formmint/madar-oss:main`. اذكر التغيير وسببَه وطريقة اختباره، واربط المهمة بعبارة `Closes #رقم_المهمة`. أرفق لقطات عند تغيير الواجهة.

قبل الإرسال، جرّب إضافة عميل ومشروع ومهمة، ثم حدّث الصفحة وبدّل اللغة. يكفي أن يكون كل طلب دمج حول تغيير واحد يمكن مراجعته.

## English

1. Browse [open issues](https://github.com/formmint/madar-oss/issues) and leave a short comment on the issue you want to work on. For bug reports, include reproduction steps, expected and actual results, browser, and interface language.
2. Fork the repository and branch from `main`. The current implementation lives in `index.html`. Follow the [run instructions](README.md#try-the-current-prototype).
3. Update Arabic and English together when changing interface text. Check RTL, LTR, and a narrow viewport. Use fictional data in tests and screenshots.
4. Open a pull request against `formmint/madar-oss:main`. Describe the change, why it is needed, and how you tested it. Link an issue with `Closes #123`, replacing 123 with its number. Attach screenshots for visible changes.

Before submitting, create a client, project, and task, refresh the page, and switch languages. Keep each pull request focused on one reviewable change.
